## Acceptance

- `dashboard cloudflare.login` creates `./tunnel` when missing and runs the documented `cloudflared tunnel login` container workflow against the current project
- `dashboard cloudflare.create <DOMAIN_ID>` accepts the explicit argument or `.env` fallback, persists the selected domain id in the project `.env`, and runs the documented `cloudflared tunnel create` container workflow

- `dashboard cloudflare.dns <DOMAIN_ID> <DOMAIN_NAME>` accepts explicit values or `.env` fallbacks, persists the hostname, and runs the documented `cloudflared tunnel route dns` container workflow
